# 楼梯视图与楼梯节点配置

状态：已由 GPT-6 Astra 审查并采纳修订，进入实现。2026-10-17。

## 目标与已确认规则

辅助线路设计：选择楼梯字母，在整张地图同时高亮各层位置。提供 Graph Editor 之后的独立楼梯视图，以及 Course Setting 内入口。

楼梯身份大小写不敏感。A 表示向上一层的节点端口，a 表示向下一层的端口；旋转楼梯节点同时具有 A/a。所有新楼梯连接双向，自动 ignoreLength；上/下不是单向通行限制。同层普通楼梯上下入口可以是不同节点，旋转楼梯可以共享一个节点。不要自动连接同层上下入口，保留真实走廊距离。

楼层顺序独立配置，从低到高排列，复用 3D Model 已有楼层编号作为候选。顺序显式保存，不依赖地图页码或节点出现顺序；缺少中间层节点不跨层匹配。无配置时先配置顺序再自动连接。

## 数据和同步

节点保存楼梯身份、楼层、上/下/上下端口。现有 vertices 是唯一坐标来源，edges 是唯一实际连通性来源。楼梯视图由这两者派生，不另存复制的图。楼层序列保存于 raceCourse。

自动匹配同楼梯、配置相邻楼层、互补方向；源端及目标端都唯一才生成一条双向 edge。规范方向低层到高层，label 大写、reverseLabel 小写、ignoreLength=true、oneWay=false。已有同端点 edge 不重复添加，普通边或不一致旧边不得静默覆盖。

自动连接由明确编辑操作触发，不由渲染/打开视图触发。删除 edge 保持断开，直至显式连接操作。修改配置时保留已有连接并报告冲突；歧义、跨层和旧单向边列为待处理。保留旧 graph 通行行为。

旧数据通过显式转换从双向、ignoreLength 且正反字母互补的 edge 推断节点方向；楼层由唯一包含节点的已有楼层多边形补齐。未知、重叠、不一致项保留并报告，不猜测。支持一个节点上下两种端口；冲突代码不覆盖。旧 edge 编辑仍立即反映实际连通性；新节点元数据与旧 edge 冲突须显示诊断。

## 交互

Graph Editor 选节点可设置楼梯代码、楼层和端口，选择“保存并连接”时匹配；普通保存不增边。另提供先选源节点、再点目标节点的连接模式，无需长距离拖动；Esc 取消。缺层、多候选用户明确选择目标，跨层手动连接需明确展示。

独立楼梯视图与 Course Setting 共享选择器及 Canvas 高亮，紫色节点环和代码/楼层/方向标签；显示各层节点列表并可定位。提供全体位置定位、连接线开关、清除选择。查看模式不创建或移动 graph 节点。Canvas 禁用原生选择，绘制/拖动事件 preventDefault。

紧凑固定工具栏，图标按钮带 tooltip。主要操作快捷键写入说明对话框，输入框内不触发快捷键。

楼层顺序编辑器复用于 3D Model 和楼梯设置；重复楼层不允许，使用中楼层移除或重排需显示连接影响，不自动改动已有通行关系。

## 持久化与兼容

所有处理本地完成。完整事件 JSON 保存新增字段，图 JSON 导入导出应保存楼梯节点及顺序。XML 保持现有 graph 可通行关系；新增元数据若不支持需明确告知，不能声称无损往返。对一次配置操作原子更新 vertices/edges，支持撤销重做。

## 验收和测试

覆盖普通分离上下节点、旋转共享节点、大小写、相邻非连续编号楼层、缺层、多候选、已有重复/普通/单向边、断开后重载、旧图转换、节点移动/删除/重命名、楼层重排诊断、JSON 持久化及 XML 兼容。E2E 覆盖标注、自动连接、点选连接和两个界面的楼梯高亮。

以用户提供的王府井事件为回归样例：591 节点、753 edges、7 个楼层多边形；转换前后现有 edges 的通行属性必须不变。测试 fixture 只保存所需 graph/多边形数据，不复制嵌入 PDF。

## 实现说明

现有楼层界面为 3D Model 的多边形 Level/Floor 属性；尚无独立楼层顺序。新增顺序配置复用该入口。核心匹配、转换和诊断逻辑放 packages/core；渲染共享 Canvas 函数。同步更新帮助和项目文档。

## 独立审查结论与决策

审查模型：GPT-6 Astra。采纳：节点 stair={code,floor,port}，code 大写规范化并支持数字后缀；stairFloorOrder 为独立数值数组。普通保存、移动、打开界面和重排楼层不增边，只有明确 Save & connect/Connect 才增边。旧边可从高到低保存，按标签及配置楼层顺序交叉校验，保留全部 edge 原始属性。任意方向已有同端点边均禁止另建。同层多个多边形不等于重复楼层。Graph JSON 导入旧文件清空楼层顺序配置。新 Canvas 高亮不要求重写既有 SVG 编辑器。

## 使用方式与验证

1. 打开事件，在 Stairs / Graph Editor / 3D Model 输入并保存从低到高的楼层顺序。王府井例子为 `-2,-1,1,2,3,4,5`。
2. 已有图先在 Stairs 点击转换图标：只补充可确定的节点标注，原始边全部保留。诊断列出不一致或不完整项。
3. Graph Editor 或 Stairs 选择节点，填写代码、楼层和端口。保存只更新标注；保存并连接仅匹配该节点相关的唯一相邻目标。
4. Stairs 中选源节点，按 C，再点击地图节点或节点列表完成连接。跨层连接需要明确确认。普通边占用同端点时需先在原编辑器处理，系统不覆盖。
5. 选择具体代码查看所有层位置；All stairs 显示全部，None/Esc 清除。Course Setting 使用相同选择器和 Canvas 高亮。
6. 按应用原有 Ctrl/Cmd+S 保存事件到 JSON 和启用的浏览器存储。节点面板“保存”提交当前编辑到事件；应用文件保存仍沿用原有工作流。

快捷键：节点表单 Ctrl/Cmd+Enter 保存，Alt+Enter 保存并连接；楼层顺序输入框 Enter 保存；C 点选连接；F 定位全部选中楼梯节点；L 显示/隐藏连线；Esc 取消连接并清除高亮；? 帮助；Ctrl/Cmd+Z 撤销楼梯操作；Ctrl/Cmd+Shift+Z 重做。输入区域保留原生快捷键。撤销历史最多30步；其他编辑器修改事件后，不允许用旧楼梯历史覆盖新修改。

JSON 完整保留标注和顺序。IOF XML 和 CSV 保留旧图路由表示，不保留新增节点元数据；XML 导出时有明确提示。王府井图和 IOF 线路作为本地测试样例，嵌入地图未复制到测试仓库。

独立实现审查另修复：空选择不能当成全选；跨层普通边必须报告 ignoreLength 冲突。验收包含核心匹配/转换/诊断、JSON/IOF导入导出、浏览器保存重载、两处高亮、显式连接、断开后普通保存、撤销。
